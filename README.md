# 星图画廊 · 项目总览

## 这是什么

一套给 **DouK-Downloader** 套壳的博主作品库，叫 **星图画廊**（内核沿用 DouK Lite），装在：

```
D:\Application\douyindownload\DouK-Lite\
```

双击 `星图画廊` 快捷方式（或 `DouK-Lite\scripts\启动.cmd`）使用。**画廊、下载、工具、截帧**四页：画廊管已下载的博主和作品，下载负责解析与勾选下载，工具做实况照片转换，截帧做专业级逐帧播放与 PNG 导出。原程序 `DouK-Downloader.exe` 一个字节都没改，界面是外挂的。

## 为什么要套壳

`DouK-Downloader.exe` 是 cx_Freeze 打包的 Python 3.12 程序，PE 子系统是 `WINDOWS_CUI`——它就是个黑窗口文字菜单，界面逻辑编译进 exe 里，安装包内没有 tkinter，也没有 html/css。**换皮这条路是死的**，所以改成在外面套一层界面，复用它自带的本地 API。

内核是 [JoeanAmier/TikTokDownloader](https://github.com/JoeanAmier/TikTokDownloader) 的上游代码，`lib/src/` 下是 `.pyc`（magic `cb0d0d0a` = Python 3.12）。

## 架构

```
启动.cmd
  ├─ 检测 127.0.0.1:5555 有没有起来
  ├─ 没起来 → echo 7 | DouK-Downloader.exe   （7 = Web API 模式）
  ├─ run_server.cmd → python.exe -u server.py > server.log
  └─ Chrome --app=http://127.0.0.1:8765/     （用户明确要 Chrome，不要 Edge）
```

- 后端入口 `server.py` + `douk_lite\` 模块包纯标准库实现，`ThreadingHTTPServer`。
- 前端 `web/` 三件套：`index.html` / `style.css` / `app.js`，无外部依赖。
- 内置 Python 3.12 embeddable 放在 `python\`，免安装，约 11MB。
- 上游 FastAPI 只返回数据、不下载文件；下载由 `douk_lite/downloader.py` 用 urllib 完成（自动兼容 `settings.json` 中的字典/字符串 Cookie），写 `.part` 再按文件头嗅探扩展名并 `replace`。

## 能做什么

- 画廊首页：博主墙 + 全部作品流；博主卡片显示作品 / 文件 / 占用，点进去看她的全部作品
- 全部作品按时间混排，按视频 / 图集 / 实况筛选，按博主过滤，搜标题或昵称，分页加载
- 作品查看器：大图、HEIC 实时预览、视频拖进度条与内嵌逐帧条；左右键翻页；支持「抽这一帧」、PNG 存图或移入系统回收站
- 单个作品下载（视频 / 图集 / 实况）
- 博主主页全部作品下载，支持「发布 / 收藏」两个页签（上游只支持这两种），解析清单支持预标「已存在」、按「全部 / 未下载 / 已存在」筛选、「只选未下载」及分页展开（支持千条以上大号）
- 实况照片一键转 iPhone 格式（HEIC + MOV 配对），成品进 `LivePhotos\`
- 独立「截帧」页：按博主分组展开全部视频（无数量漏扫），自动探测 FPS、胶片缩略图条、方向键逐帧步进，导出原分辨率 PNG 进 `截帧\`；浏览器无法解码的编码可一键由 `ffmpeg` 挑最佳帧
- 文件分流：普通图片留博主文件夹根目录，实况进 `实况\`，普通视频进 `视频\`
- 图片取最清晰源（去掉 CDN 的 `~tplv-…` 压缩模板）
- 主页解析一律采用日期窗 + 游标分段爬取（带单段缩窗重试、置顶时间剔除、增量缓存、断点续爬）；等太久可以随时「停止解析」，已取到的作品会保留并显示，也写进缓存，下次接着往后补
- 「快速解析」勾选后只取最近 30 天，几秒出结果，适合只想看新作品；更早的作品这次不列，缓存里的旧作品照样在
- 博主记忆：解析主页就把博主记进画廊，名单存在 `cache\creators.json`
- 本地作品库：按 `日期 时间-类型-昵称-描述[_序号]` 的文件名归组，不用额外索引文件；运行时错误与状态写入 `logs\app.log`（UTF-8 轮转日志）
- 解析时显示当前阶段、已取条数、已等秒数；关掉浏览器窗口后后端自动退出

## 输出目录

```
<保存根目录>\UID<uid>_<昵称>_发布作品\
  ├─ 普通图片
  ├─ 实况\      （实况视频）
  └─ 视频\      （普通视频）
<保存根目录>\LivePhotos\<原视频名>.HEIC + .MOV
<保存根目录>\截帧\<原博主文件夹>\<原视频名>_帧_00-00-01.jpg
```

文件夹名可用 `folder_template` 改，占位符 `{uid} {sec_uid} {nickname} {date}`。注意：改了模板，同一个博主会建新文件夹，旧文件夹不会跟着改名。

## 版本机制（容易踩）

`web/build.txt` 是唯一版本号。`server.py` 启动时把它的字节写进 `server.build`，`启动.cmd` 用 `fc /b` 比对，不一致就杀掉 python 重启。

**改 `server.py` 必须顺手改 `web/build.txt`**，否则启动器认为没更新、不重启，你看到的还是旧接口，症状是前端报 `Unexpected token '<'`（拿到的是 HTML 404）。

## 贯穿全程的教训

- **能一次整包拿的，别拆成自己算游标的分段。** 抖音的 `max_cursor` / 日期过滤语义比想象的脆，分段逻辑自己提前停了，132 条只给 50 条。
- **扩展名不能看 URL 猜。** 抖音视频地址没有后缀，实况帖的 downloads 是 mp4 和 jpg 混合的。先下成 `.part`，读文件头（`ftyp` / `FFD8FF` / `RIFF`）再改名。
- **给用户的中文 `.cmd` 一律存 GBK(cp936)、不写 `chcp`。** 存成 UTF-8 无 BOM + `chcp 65001` 再夹中文，cmd.exe 按字节解析会顶掉位置，`if` 块的右括号读不到就挂死。
- **exiftool 碰中文文件名会莫名报错。** 实况转换全程在 `%TEMP%` 的纯 ASCII 目录里做，最后用 Python 改成中文成品名。
- **沙箱里测完要把 `server.build` 写回旧版本号**，否则用户点启动器会以为服务已经是新代码。
