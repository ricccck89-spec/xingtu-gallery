# 星图画廊（Xingtu Gallery）

> 本地抖音 / 小红书博主作品库与媒体工具台：画廊管理、发现推荐、链接解析下载、实况照片转 iPhone（HEIC + MOV）以及视频逐帧截取。

## 这是什么

**星图画廊**是一套纯本地运行的 Windows 桌面 Web 应用（内核为 `DouK-Lite`），定位是「**本地博主作品库 + 一站式素材工具台**」。双击根目录下的 `DouK-Lite\星图画廊.vbs`（或 `DouK-Lite\scripts\启动.cmd`）即可在独立 Chrome 应用窗口中打开，关闭窗口后后台服务自动退出。

核心能力分为三大模块：

- **画廊**：博主墙与全部作品流。按博主或时间浏览已下载的图片、视频、实况；支持按类型筛选、搜索、排序与分页加载；内置作品查看器（HEIC 实时预览、视频内嵌逐帧条、移入系统回收站）。
- **发现**：不用在网页间来回切换，直接在本地刷**小红书主页推荐**与**抖音推荐**，支持分类切换、关键词过滤、查看博主主页与一键批量勾选下载；同时内置**指定链接解析下载**面板（支持抖音 / 小红书单个作品与博主全部作品）。
- **工具**：可扩展的本地素材处理工作台，当前内置两项工具：
  - **实况照片**：扫描保存目录中的实况视频，一键封装为 iPhone 可识别的 `HEIC + MOV` 配对实况照片（成品输出到 `LivePhotos\`）。
  - **视频截帧**：按博主分组展开本地视频，支持 FPS 自动探测、胶片缩略图条、方向键逐帧步进、原分辨率 PNG 导出进 `截帧\`，并支持对浏览器无法解码的视频调用 `ffmpeg` 自动挑最清晰一帧。

## 架构概览

项目已完全独立运行，不再依赖任何外部套壳程序：

```
启动.cmd
  ├─ 检测 127.0.0.1:8765 是否已启动（比对 logs\server.build 与 web\build.txt）
  ├─ 未启动或版本更新 → python\pythonw.exe -u server.py > logs\server.log
  └─ Chrome --app=http://127.0.0.1:8765/（未找到 Chrome 时回退默认浏览器）
```

- **后端（`DouK-Lite/server.py` + `DouK-Lite/douk_lite/`）**：
  - `http_server.py`：基于标准库 `ThreadingHTTPServer` 的本地 HTTP 服务与 SSE 心跳自动退出机制。
  - `douk_api.py`：基于 `f2` 的抖音解析引擎（单个作品、博主发布/收藏、日期窗 + 游标分段爬取、断点续爬与增量缓存）。
  - `xhs_api.py`：小红书推荐流、博主主页与笔记解析引擎。
  - `downloader.py`：并发下载器，写 `.part` 临时文件后按文件头嗅探真实扩展名，支持图集高清原图探测。
  - `gallery.py`：本地作品库扫描与按文件名规范归组（无需额外数据库索引）。
  - `media.py`：缩略图缓存、视频抽帧/截帧落盘、实况照片转码封装与回收站清理。
  - `config.py` / `state.py`：配置管理、UTF-8 轮转日志与任务状态。
- **前端（`DouK-Lite/web/`）**：`index.html` / `style.css` / `app.js` 原生三件套，无外部构建依赖。
- **内置运行环境**：免安装 Python 3.12 embeddable（`python\`）与离线媒体工具（`tools\ffmpeg.exe`、`tools\exiftool.exe`）。

## 目录与文件归档规则

```text
<保存根目录>\
  ├─ UID<uid>_<昵称>_发布作品\
  │    ├─ <日期 时间>-图集-<昵称>-<标题>_1.jpeg   # 普通图片留在博主根目录
  │    ├─ 实况\                                   # 实况帖子的动图视频 (.mp4)
  │    └─ 视频\                                   # 普通视频 (.mp4)
  ├─ LivePhotos\                                  # 「工具 → 实况照片」成品 (.HEIC + .MOV)
  └─ 截帧\                                        # 「工具 → 视频截帧」与查看器抽帧成品 (.png / .jpg)
       └─ <原博主文件夹>\
```

- 博主文件夹命名可通过设置中的 `folder_template` 自定义（支持 `{uid}`、`{nickname}`、`{sec_uid}`、`{date}`）。
- 实况子文件夹与视频子文件夹名称均可在设置中调整。

## 开发与版本机制

- `DouK-Lite/web/build.txt` 是服务版本标识。`server.py` 启动时会将其内容写入 `logs\server.build`；`启动.cmd` 通过 `fc /b` 比对两者，不一致时会自动重启后台进程。
- **修改后端代码（`douk_lite/*.py` 或 `server.py`）后请同步更新 `DouK-Lite/web/build.txt`**，以确保重启应用时自动加载最新后台代码。
- 核心单元测试位于 `DouK-Lite/tests/test_core.py`。

## 关键工程经验

- **文件扩展名以文件头为准**：抖音/小红书媒体地址常无后缀或带压缩模板，下载时先落 `.part`，再按文件头（`ftyp` / `FFD8FF` / `RIFF` 等）嗅探改名。
- **分段断点续爬**：博主主页全量解析采用日期窗 + 游标分段抓取并持久化到 `cache\accounts\`，支持随时「停止解析」保留已取列表，再次解析默认仅增量补齐最近 30 天。
- **中文批处理与外部工具兼容**：面向用户的 `.cmd` 脚本统一采用 GBK（CP936）编码；`exiftool` 写入元数据时在 `%TEMP%` 纯 ASCII 路径完成，最后再原子重命名为中文成品名。
- **更多设计文档**：见 `docs/` 目录（含 [现状审计与 2.0 规划](docs/05-现状审计与2.0规划.md)）。
