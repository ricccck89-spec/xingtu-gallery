# 项目指令草案

建好 Claude 项目后，可以把下面这段粘进「项目指令 / 自定义指令」里，让每次新对话都知道上下文。

---

这个项目围绕 **星图画廊（DouK Lite 内核）** —— 给 DouK-Downloader 套的本地博主作品库，装在 `D:\Application\douyindownload\DouK-Lite\`。界面分四页：**画廊**（默认页，博主墙 + 全部作品流）、**下载**（解析、勾选、下载）、**工具**（实况照片转换）、**截帧**（独立逐帧播放器）。

背景要点：

- 原程序 `DouK-Downloader.exe` 是 cx_Freeze 打包的 Python 3.12 控制台程序（`WINDOWS_CUI`），界面逻辑编译在 exe 里，**不可能换皮**。我们的做法是外挂界面，复用它自带的 FastAPI（`127.0.0.1:5555`）做解析和签名。
- 代码入口是 `DouK-Lite\server.py`（调用 `douk_lite\` 包内的 7 个纯标准库模块：`config.py` / `state.py` / `douk_api.py` / `downloader.py` / `gallery.py` / `media.py` / `http_server.py`）和 `web\` 三件套（`index.html` / `style.css` / `app.js`）。`tools\` 里有 ffmpeg / exiftool，`python\` 是免安装的 3.12（内置 Pillow + pillow-heif）。
- **改后端或前端代码必须同时更新 `web/build.txt`**，否则启动器 `fc /b` 认为没更新、不重启。（测试完别把 `logs/server.build` 提前改成新版本号。）
- 运行日志写向 `DouK-Lite\logs\app.log`（UTF-8 轮转日志）；`tests\test_core.py` 和 `tests\selftest_parse.py` 为核心与解析回归测试。
- 「我的博主」名单存在 `DouK-Lite\cache\creators.json`，解析主页时按 `sec_uid` 去重写入（下载时更新下载次数），前端只读。
- 作品库不另建索引：直接扫保存目录里各博主文件夹，按文件名前缀 `日期 时间-类型-昵称-描述[_序号]` 把分片归成一条作品；扫描结果缓存在内存 `_lib_cache`，下载完或设置变更时作废。`/api/asset` 支持 Range，视频能拖进度条。
- 画廊首页走 `/api/gallery`：一次返回博主列表、统计、全部作品（跨博主按时间混排），支持 `type` / `folder` / `q` / `offset` / `limit` / `refresh`；`counts.types` 是受博主/搜索过滤后的分类计数。`/api/library` 仍然只给单个博主。
- 视频抽帧：「工具 → 视频抽帧」走 `/api/frame/scan`（扫保存目录视频，跳过 `LivePhotos` / `截帧`，缓存 20 秒）和 `/api/frame`（ffmpeg 抽当前帧或 `thumbnail` 自动挑帧）。成品目录是 `<root>\截帧\<原文件夹>\<原视频名>_帧_HH-MM-SS.jpg`；`截帧` 已加入 `SKIP_DIRS`，不会被当成博主文件夹，也不进作品库。作品查看器里对视频也能直接「抽这一帧」。
- 主页解析**一律分段**：上游每翻一页会随机歇 1.5–33 秒（平均 6 秒），一千个作品的整包请求必然 timed out（旧版就是这样永远下不下来）。`run_account_job` 改成自己带日期窗+游标一段段往回爬（`PARSE_CHUNK_TIMEOUT=240`，每段约 100 条，单段失败减半重试、最多连续 5 次），每段落盘；半截缓存从最新往下接，碰到整段都是已知作品就跳到缓存最老一条继续（`jump_to`），不跳过年份空档。**不要再发不带日期窗的整包请求。**
- 解析任务必须能中止：上游请求一律走 `_post_cancellable`（子线程发请求、主线程每 0.35 秒看 `job["cancelled"]`）。停止后保留已取到的作品、照常落盘（`complete` 保持原值），前端提示「已停止解析」。
- 「快速解析」只向后端要最近 30 天（`recent_days=30`），一个请求就回；它不能把缓存标成 `complete`，否则下次会误以为已经拉全。
- 解析进度字段：`phase` / `note` / `count` / `cached` / `pages` / `waiting`，`/api/job` 原样返回，前端轮询渲染。
- 扩展名靠读文件头 sniff，不能看 URL 猜。
- 中文 `.cmd` / `.vbs` 一律存 GBK、不写 `chcp`。图标是 `web\icon.ico`（16–256 多尺寸），`/favicon.ico`、`/icon.png`、`/icon-180.png` 由 server.py 直接吐（Chrome 应用窗口和任务栏就用它）。
- exiftool 不碰中文路径，实况转换全程在 `%TEMP%` 里做。

用户环境：Windows 11，不打字命令行就双击带星图标的 `星图画廊` 快捷方式（= `星图画廊.vbs` → `DouK-Lite\scripts\启动.cmd`，全程无黑框），浏览器用 Chrome。当前默认下载根目录可在设置里切换（如 `E:\Files\pics` 或 `D:\Application\douyindownload\Volume`）。
