# 04 · 图片与实况照片归类

> 会话 ID：`local_1237fa8b-c07b-47c3-a98d-ded89673138c`
> 状态：idle（已完成）

## 起点

下载下来的文件全堆在博主文件夹根目录，图片、实况、视频混在一起。你要求按「爱吃米饭」的既有结构统一：**图片留根目录，实况和视频各进子文件夹**。

## 做法

按文件名里的类型字段分类——李闽轩和鞠婧祎的文件名都带「图集 / 实况 / 视频」，比按文件大小猜更准。

移动 **551 个文件**，前后总数完全对得上，没有覆盖。

## 结果

```
李闽轩/        根目录 749 张图（691 图集 + 58 实况封面）
  ├ 实况/      42 个（实测 41 个 <3s，全部 <10s）
  └ 视频/      202 个

鞠婧祎/        根目录 1 张图
  ├ 实况/      6 个
  └ 视频/      155 个

LivePhotos/
  ├ _index.json（转换工具的索引，没动）
  └ 爱吃米饭/
      ├ 73 个 HEIC 封面
      └ 实况/    73 个 MOV
```

## 注意

- 实况的静态封面按你的要求留在根目录，所以李闽轩那 58 张实况 JPG 现在和普通图集混在一起。
- `爱吃米饭` 原样未动。
- 这个结构后来固化进了 `server.py` 的 `target_folder()`：下载后按 sniff 出来的真实扩展名决定放哪个子文件夹，不再按帖子 type 判断（一条实况帖里静态图和 mp4 是混的）。
- 历史误放的可以用设置里的「整理」按钮修：把 `实况\` 里的图片挪回博主文件夹，视频不动，同名跳过。
