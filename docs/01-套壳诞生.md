# 01 · 抖音live图批量转换

> 会话 ID：`local_bdce1759-4317-4b27-93de-e07b3161edff`
> 状态：idle（已完成）

## 起点

你要求给抖音下载做界面、支持实况图。原始程序 `DouK-Downloader.exe` 看起来像有界面，其实只是黑窗口里的文字菜单。

## 做了什么

查了 PE 头确认子系统是 `WINDOWS_CUI`，安装包里没有任何界面代码（无 tkinter、无 html/css），界面逻辑编译在 exe 里——**换皮不可能**。于是改成在外面套一层全新界面，复用它的内核：原程序自带本地 API 服务 `127.0.0.1:5555`，负责解析和签名，新界面只做取数据 + 落盘。

新界面按你的要求砍到只剩两件事：**单个作品**、**博主全部作品**。实况图进 `<博主文件夹>\实况\`，普通作品留在根目录。最高画质做成设置开关，默认开，打开时同步写回原程序的 `settings.json`（`original_quality`），所以原程序自己跑也是这个设置。

技术上不依赖本机装 Python——目录里塞了官方免安装的 Python 3.12，`server.py` 只用标准库，零安装。

## 过程中修掉的问题

- 下载时结果区重复出现、停止按钮常驻、模式标签不同步
- CSS 类名撞车：顶栏和进度条都叫 `.bar`，进度条被 `display:flex` 撑成粗条，`[hidden]` 也失效 → 进度条改名 `.track`
- 状态栏加了「点击重连」兜底
- 核对过菜单序号：`7` 确实是 Web API 模式

## 怎么验证的

用模拟 API 把「解析 → 下载 → 进度 → 落盘」整条链路跑通，确认实况进了子文件夹、多图加 `_1/_2` 后缀、前端控制台无报错，并逐张看了界面截图。

## 当时的遗留

沙箱连不到真实抖音服务，所以真实链接解析、以及 `启动.cmd` 自动喂 `7` 进 API 模式这两步需要你本机首次运行时验证。如果右上角显示「未连接」，点一下状态标签重试；再不行手动打开 `DouK-Downloader.exe` 选第 7 项。
