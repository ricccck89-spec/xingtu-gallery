# 星图画廊（DouK Lite 内核）

一个本地博主作品库：把下载过的博主的图片、视频、实况收进画廊，按博主和时间浏览、回看；下载只是其中一页。界面套在 DouK-Downloader 外面，**不改动原程序任何文件**。

## 怎么用

双击桌面（或 DouK-Lite 目录里）带星图标的 **`星图画廊`** 快捷方式。它在 `星图画廊.vbs` 上；快捷方式**只在第一次运行时生成一次**（目录 + 桌面各一枚），之后启动器不会再碰你的桌面——你把它删了就不会再冒出来。想重新生成，删掉 `cache\快捷方式已完成.txt` 再双击 `星图画廊.vbs`。

它会做三件事：把原程序以「Web API 模式」拉起来（最小化的黑窗口，不用管它）→ 启动本地界面服务（完全后台，没有黑框）→ 用 **Chrome 的应用窗口**打开界面（独立 profile，不会动你正在开的 Chrome 窗口），窗口和任务栏图标就是那枚星图。

想固定到任务栏：把快捷方式拖到任务栏上，或者窗口开着时右键任务栏图标 → 固定。

界面分三页：

- **画廊**（默认页）：博主墙 + 全部作品流。点博主卡片进她的作品页，可以按视频 / 图集 / 实况筛选、搜索、翻页；「全部作品」按时间混排所有博主的作品；查看器内置视频逐帧条与回收站安全删除
- **发现**：刷小红书主页推荐 / 抖音推荐，支持看Ta主页与批量勾选下载；右上角「+ 指定链接下载」展开链接解析面板，支持预标「已存在」、按「未下载/已存在」筛选、分页勾选与并发下载
- **工具**：本地素材处理工作台，集成**实况照片**（批量转 iPhone HEIC + MOV）与**视频截帧**（独立逐帧播放器，支持方向键逐帧步进、胶片缩略图条与原分辨率 PNG 落盘），后续会继续扩展更多工具

然后在界面里：

- **单个作品**：粘贴作品链接或分享文案 → 解析 → 下载
- **博主全部作品**：粘贴博主主页链接 → 解析 → 看到作品清单（支持筛选「未下载」、点击「只选未下载」及分页展开千条大号）→ 下载全部 / 选中项
- 解析博主之后，结果区顶部有 **发布 / 收藏** 两个分栏，可以来回切（抖音的「喜欢」是私密的，原程序也只接口了这两个）
- **分享文案可以直接粘**：`长按复制此条消息，打开抖音搜索，查看TA的更多作品。 https://v.douyin.com/xxxx/` 这种整段丢进去就行，程序会把前面的中文去掉，解析成功后输入框会自动变成干净的网址
- 粘进输入框就自动开始解析；按 `Ctrl K`（或在空白处按 `/`）可以直接跳到输入框
- 左侧栏「保存到」是个输入框，**直接改成别的目录、回车就生效**，不用进设置
- **清单里带预览图**：作品列表每行左边有缩略图，下载前用抖音封面、下完之后换成本地文件抽的图；实况列表显示每条视频的画面（视频用 ffmpeg 抽一帧，图片直接缩）。缩略图缓存在 `cache\thumbs\`，删掉不影响任何东西
- **解析是分段往回爬**：不再让原程序一口气翻完整个主页（它每翻一页还要随机歇几秒，一千个作品要五六分钟，肯定超时），而是自己带日期窗和游标一段一段往前取；进度里显示「分段获取 · 已取 N 个 · 第 M 段」
- **大号也能拿全**：某一段超时就缩小范围重试，不会因为一次失败整次放弃；每段都写进 `cache\accounts\`，中途停止或断掉，下次解析从最老的一条接着爬，已经取到的不丢
- **同一个博主第二次解析快得多**：缓存完整时只补最近 30 天，通常一两秒；博主发了新作品会补进来。想强制全量重来就把 `cache\accounts\` 里对应的 json 删掉
- **关窗口就关后台**：页面开着一条常连（SSE），窗口一关后端就退出（顺带收掉 DouK 的隐藏 API 进程），大约 10 秒内结束；刷新页面不会误关。注意正在下载/转换时关窗口会中断当前任务，下次再下会自动跳过已完成的

## 下载到哪

```
Volume\
  UID<数字>_<博主昵称>_发布作品\
    2024-01-06 18.40.17-图集-昵称-标题_1.jpeg   ← 照片直接放这里
    2024-01-06 18.40.17-图集-昵称-标题_2.jpeg
    视频\                                      ← 普通视频
      2024-01-07 20.11.03-视频-昵称-标题.mp4
    实况\                                      ← 只有实况的动图视频
      2024-01-06 18.40.17-实况-昵称-标题.mp4
  截帧\                                       ← 「工具 → 视频抽帧」的成品
    同一博主文件夹\
      2024-01-06 18.40.17-实况-昵称-标题_帧_00-00-01.jpg
  LivePhotos\                                 ← 实况转 iPhone 的成品
```

**按文件真实类型分流，不看帖子标题**：一条实况帖里往往既有动图（mp4）又有静态图（jpeg），动图进 `实况\`，静态图直接留在博主文件夹；普通视频进 `视频\`。两个子文件夹的名字都能在设置里改。

## 实况照片（mp4 → iPhone 能认的 Live Photo）

「工具 → 实况照片」，它会扫描保存目录里**文件名带「实况」**的视频，缺多少补多少，已经转好的跳过。下载完一条帖子后，结果区也会出现「转实况照片」按钮，点了直接跳过去。

转换做三件事：从画面里挑一帧做封面（`thumbnail` 滤镜选最清楚的一帧）→ 视频取前 3 秒重新封装成 MOV → 两个文件写同一个 UUID（HEIC 写进 Apple MakerNote 的 `ContentIdentifier`，MOV 写进 `QuickTime:ContentIdentifier`）。iOS 认配对靠的就是这个 ID，所以两张必须一致。

成品在 **`<保存目录>\LivePhotos\`**：

```
LivePhotos\
  2024-01-06 18.40.17-实况-昵称-标题.HEIC   ← 封面（HEIC 组件不可用时退成 JPG，照样能配对）
  2024-01-06 18.40.17-实况-昵称-标题.MOV    ← 前 3 秒，H.264 + AAC
  2024-01-07 09.12.55-实况-昵称-另一条.HEIC
  2024-01-07 09.12.55-实况-昵称-另一条.MOV
  _index.json       ← 记录哪条视频转成了哪一组，用来跳过重复转换
```

文件名**沿用原视频的名字**（也就是下载时的「时间-实况-昵称-标题」），一眼能对上原帖；不同博主撞名时自动加 `_2`、`_3`。删掉某一组再扫，会重新按原名转一遍。

**导入 iPhone**：爱思助手 → 我的设备 → 照片 → 相机胶卷 → **导入实况照片 → 批量导入**（靠同名 HEIC + MOV 配对）。iCloud 网页版上传也会自动合并。**微信 / QQ 传过去会把元数据剥掉**，Windows 资源管理器直接拷 DCIM 也不行。

限制：Apple 规格要求实况视频不超过 3 秒，超出的会截断；封面分辨率跟源视频一样（一般 720p 到 1080p）。

转换用的工具都在 `tools\` 里，解压后约 100MB，离线可用：`ffmpeg.exe` 负责抽帧和封装，`exiftool.exe`（连同 `exiftool_files\`）负责写配对信息；HEIC 编码用的是内置 Python 里的 Pillow + pillow-heif（在 `python\Lib\site-packages\`）。少任何一个，界面会直接提示。

## 画廊

画廊不另建索引，直接扫保存目录：每个博主文件夹按文件名前缀（`日期 时间-类型-昵称-描述[_序号]`）归成一条作品，结果缓存在内存里，下载完或点「刷新」就重新扫。

- **博主墙**：每位博主一张卡片，封面用她最新的作品；卡片上写着作品数、文件数、占用空间和最近活动时间
- **全部作品**：跨博主按时间混排，可以按类型（视频 / 图集 / 实况）筛选、按博主过滤、搜标题或昵称；每页 60 条，点「加载更多」往后翻
- **博主页**：点卡片进入，头部是头像、UID、统计；下面同样能按类型筛选和搜索
- **查看器**：点作品看大图和视频（视频支持拖动进度条）；左右方向键翻上一张 / 下一张；视频右上角有「抽这一帧」，直接按当前播放位置存一张图

## 视频抽帧

「工具 → 视频抽帧」会扫描保存目录里的视频（跳过 `LivePhotos\` 和 `截帧\`），左边列表选一条，右边播放器挑时间点：

- **按当前画面抽帧**：存下播放器当前时间点的那一帧
- **自动挑最清晰一帧**：用 ffmpeg 的 `thumbnail` 滤镜在整条视频里挑
- 成品统一放进 `<保存目录>\截帧\<原博主/子文件夹>\`，文件名是 `原视频名_帧_00-00-01.jpg`，不会混进作品库

## 设置

点左侧栏底部的「设置」：

- **保存到**：必须是完整路径，例如 `D:\Application\douyindownload\Volume`；点「浏览…」可以直接选文件夹
- **博主文件夹命名**：模板字符串，可用占位符 `{uid}` `{nickname}` `{sec_uid}` `{date}`，默认 `UID{uid}_{nickname}_发布作品`，下面有实时预览
- **实况子文件夹名**：默认 `实况`，只装实况帖里的动图视频
- **视频子文件夹名**：默认 `视频`，装普通视频
- **整理已下载**：早期版本把实况帖里的静态图也塞进了 `实况\`，点一下就挪回博主文件夹（不动视频，同名跳过）
- **最高画质**：默认开启。开启后优先抓原画视频（对应原程序 `settings.json` 里的 `original_quality`），文件更大、耗时略长
- **图片取最清晰源**：默认开启。图集里的图片地址带 `~tplv-dy-aweme-images:q75.webp` 这类压缩模板，不是原图；开启后会在下载前探一遍「去掉模板 / q100 / 换 jpeg」的几种取法，按分辨率挑最大的那张，探不到就老老实实用原地址
- **同时下载数**：1–6，默认 3

最高画质的开关会同步写回原程序的 `settings.json`，所以原程序自己下载时也是这个设置。

## 实况图

抖音的「实况」帖，下下来的是**动图本体（mp4）**，会放在 `实况\` 子文件夹里；同一条帖子里如果混着静态图，那些就是 jpg。文件类型是按下回来的文件头判断的，不看地址后缀——抖音的视频地址没有 `.mp4` 后缀，靠后缀猜会全部错标成 jpeg。

要变成 iPhone 能认的实况照片（HEIC+MOV）还需要一步转换：在「工具 → 实况照片」点「开始转换」就行，工具都随包带着，成品进 `<保存目录>\LivePhotos\`。（最早的 128 组是在 Claude 沙箱里用一个临时脚本转的，现在不用了。）

## 打开文件夹

界面上有两处可以直接打开资源管理器：左侧栏「保存到」下面的小「打开」，和解析结果右上角的「打开文件夹」（会定位到这次下载的具体博主文件夹）。

## 它和原程序是什么关系

界面本身不带解析能力——抖音的签名参数（a_bogus / X-Bogus 那套）还是原程序在算。所以：

- 原程序必须处于 **Web API 模式**（端口 5555），界面才能工作
- 登录状态用的还是原程序 `settings.json` 里的 Cookie，Cookie 失效的话原程序里更新一下

`星图画廊`（快捷方式 → `星图画廊.vbs` → `scripts\启动.cmd`）会自动帮忙切到 API 模式。如果左侧显示「未连接」，点一下那个状态标签可以重试；还不行就手动双击 `DouK-Downloader.exe`，在菜单里选 **7. Web API 模式**。

```
DouK-Lite\
  星图画廊.lnk      ← 平时点这个（第一次双击 星图画廊.vbs 时自动生成）
  星图画廊.vbs      ← 真正的启动器：无黑框、失败才弹提示
  server.py         ← 后端入口（调用 douk_lite\ 包）
  config.json       ← 用户配置（保存目录、子文件夹名、并发数等）
  douk_lite\        ← 后端模块包
    config.py       ← 路径常量、配置读写、目录校验
    state.py        ← 任务状态、缓存与自动退出看门狗
    douk_api.py     ← 上游 API、链接识别、分段解析、博主名单
    downloader.py   ← 嗅探类型、高清图探测、并发下载
    gallery.py      ← 作品归组、画廊快照缓存与排序分页
    media.py        ← 缩略图、截帧、实况照片转换、回收站删除
    http_server.py  ← HTTP 路由与服务入口
  web\              ← 界面静态资源与图标（icon.ico）
  scripts\          ← 启停脚本（全 GBK 编码）
    启动.cmd        ← 启动流程本体（命令行版，排错时在这里看输出）
    停止.cmd        ← 卡住/关不掉的时候运行，精确结束后台两个进程
    start_api.cmd   ← 拉原程序的 API 模式（启动.cmd 会调用）
    run_server.cmd  ← 手动起界面服务并写 logs\server.log（正常启动不需要它）
  tests\            ← 自动化测试（selftest_parse.py / test_core.py）
  logs\             ← 运行日志与状态文件（启动日志.txt / server.log / app.log / server.pid / server.build）
  tools\            ← 实况照片转换用的 ffmpeg.exe / exiftool.exe
  cache\
    thumbs\         ← 清单缩略图缓存，删掉会自动重建
    accounts\       ← 每个博主（+发布/收藏）一份作品缓存，删掉就等于「下次从头解析」
  python\           ← 内置的免安装 Python 3.12（Lib\site-packages 里带了 HEIC 编码组件）
```

## 出问题怎么办

先运行 `scripts\停止.cmd`，再双击 `星图画廊` 重来一次。

如果界面顶上说「后台还是旧版本」，直接再双击一次 `星图画廊` 就行：它会发现正在跑的服务是旧代码，自动重启界面服务（不用先手动停止）。

快捷方式图标不对（显示成白纸/齿轮）：删掉桌面和目录里的 `星图画廊.lnk`，再双击一次 `星图画廊.vbs`，它会重新生成并指向 `web\icon.ico`。

还不行就看 `logs\` 下的日志文件：`logs\启动日志.txt` 记录启动器走到哪一步，`logs\server.log` 记录进程启动输出，`logs\app.log`（UTF-8 轮转日志）记录下载/解析/转换中的详细异常。把它们发出来基本就能定位。

窗口一直停在某句话不动，多半是脚本编码的问题——`星图画廊.vbs` 和 `scripts\` 里那几个 `.cmd` 必须是 **GBK 编码**，用记事本另存成 UTF-8 会把它弄坏。

## 已知限制

- 解析大博主要等一会儿，现在是一段一段地取，进度可见；被抖音限速时单段会失败，此时保留已取到的部分
- 原程序的日期筛选（earliest/latest）是**真的会把作品过滤掉**的，所以不能拿未来日期骗它只翻一页；界面用的是「游标 + 日期窗」一段段往回取
- 主页缓存只按 sec_uid + 分栏存，同一个博主删过作品的话缓存里还会留着旧的条目（下载时会因为文件已存在而跳过）
- 下载的是原程序解析出来的地址，原程序失效的话这里也会失效
- 「图片取最清晰源」只影响**新下载**的图；以前已经存过的（状态显示「已存在」）不会自动重下，要的话把那几张删掉再下一次
- 抖音对外只发它自己重编码后的版本，「最清晰源」是它保留的那一份，不可能是你上传时的原始文件
